# scripts 脚本索引

> 最后整理：2026-10-31。本文是 `scripts/` 的唯一入口索引；新增/移动脚本时同步更新本表。
> 原则：**运维 → `ops/`，门禁/构建/统计 → `ci/`，数据维护 → `data/`，索引同步 → `sync/`，
> 一次性诊断 → `oneoff/`，已结项 → `archive/`。**

## 1. 目录职责

| 目录 | 职责 | 是否纳入门禁 |
|---|---|---|
| `scripts/ops/` | 备份/恢复、重启/守护、状态、API Key | 是（Python + bat/ps1 编码） |
| `scripts/ci/` | 一键门禁、构建、代码量统计、前端检查 | 是 |
| `scripts/data/` | 素材导入/裁剪/清理、标签、向量、质量学习、文档翻译 | 是 |
| `scripts/sync/` | OpenViking 索引增量同步 | 是 |
| `scripts/oneoff/` | 仍可用的一次性/诊断脚本 | Python 规则 + bat/ps1 编码 |
| `scripts/archive/` | 已结项/不再维护的实验脚本 | **否**（只保留复现，不进门禁） |

## 2. 常用入口（先看这里）

| 场景 | 命令 |
|---|---|
| 一键重启后端 + 前端 + worker + 人脸服务 | `bash scripts/ops/restart.sh` / `scripts\ops\restart.bat` |
| 幂等确保服务在跑（健康检查 + 只启动缺失） | `bash scripts/ops/ensure-services.sh` |
| 查看服务状态 | `bash scripts/ops/status.sh` / `scripts\ops\status.bat` / `python scripts/ops/status.py` |
| 备份 / 恢复 | `bash scripts/ops/backup_data.sh E:/...` / `bash scripts/ops/restore_data.sh E:/... --allow-overwrite` |
| 每日备份 / 恢复计划任务 | `scripts/ops/backup_task.bat` / `scripts/ops/restore_task.bat` |
| 一键门禁（13 项） | `bash scripts/ci/test.sh` |
| Windows 快速测试子集 | `scripts\ci\test.bat`（仅 pytest + vue-tsc + vitest，不是完整门禁） |
| 前端生产构建 / 打包 | `bash scripts/ci/build_web.sh [--zip]` / `scripts\ci\build_web.bat` |
| 项目体量 / 代码量报告 | `python scripts/ci/project_stats.py` / `python scripts/ci/code_report.py` |
| 代码行数 | `bash scripts/ci/count_lines.sh` / `powershell -File scripts\ci\count_lines.ps1` |
| OpenViking 索引同步 | `bash scripts/sync/sync_openviking.sh [--full|--dry-run]` |
| 生成 API Key | `python scripts/ops/generate_api_key.py` |
| 清理测试污染文件 | `python scripts/data/clean_test_files.py [--delete]` |

> **服务启停由用户手动执行**：项目规则禁止自动执行 `restart.sh` / `ensure-services.sh`。
> 需要重启时请手动运行上面的入口。脚本移动后，Windows 任务计划与 Claude SessionStart hook
> 中写死的旧路径需要重新注册/更新（见第 5 节）。

## 3. 文件清单

### ops/ —— 运维

| 脚本 | 用途 |
|---|---|
| `backup_data.sh` | 异盘备份：SQLite 一致性快照 + SQL 明文 + storage 增量收敛 + manifest 校验 + 轮转 |
| `restore_data.sh` | 恢复：前置检查（SUCCESS/服务/磁盘/备份完整性）→ 快照 → 恢复 DB/storage/配置 → 校验 |
| `backup_task.bat` / `restore_task.bat` | Windows 任务计划包装（ASCII；备份根可用 `BACKUP_TARGET` / `BACKUP_ROOT` 覆盖） |
| `restart.sh` / `restart.bat` | 先停 supervisor/服务再启动；端口读 `backend/.env`，优先用 PID 文件/状态文件 |
| `ensure-services.sh` | 幂等确保 supervisor 在跑并等待三服务就绪（带原子锁） |
| `supervisor.py` | 守护 backend/frontend/worker：健康检查、崩溃拉起、日志轮转、资源告警、状态落盘 |
| `status.py` / `status.sh` / `status.bat` | 读后端 `/api/health/services`，失败回退 `logs/service_status.json` |
| `generate_api_key.py` | 生成破坏性接口 API Key（当前密钥只显示掩码） |

### ci/ —— 质量门禁 / 构建 / 统计

| 脚本 | 用途 |
|---|---|
| `test.sh` | 13 项一键门禁：pytest+覆盖率棘轮、ruff、vulture、mypy、迁移链、库漂移、脚本规范、vue-tsc、vitest、eslint、死代码基线、格式、移动端 tsc+jest |
| `test.bat` | Windows 快速子集：pytest + vue-tsc + vitest（不是完整门禁） |
| `build_web.sh` / `build_web.bat` | 前端生产构建（vue-tsc + vite build），可选打 zip |
| `check_scripts.py` | 脚本静态守卫：只读 sqlite 连接、入口 argparse、注释吞 def；并校验 bat 的 GBK/`chcp 936` 与 ps1 的 UTF-8 BOM |
| `check-web-dead-code.mjs` | ts-prune 死代码基线（只拦新增） |
| `check-web-format.mjs` | 只检查本次改动前端文件的 Prettier 格式 |
| `code_report.py` | 代码量体检报告（按职能分类、结构/质量指标、`--ref` 固定提交、`--json`） |
| `project_stats.py` | 项目体量统计（代码/DB/storage/仓库/测试/最大源文件；路径跟随 `settings`） |
| `count_lines.sh` / `count_lines.ps1` | 分语言代码行数（总行/代码/空行/注释） |
| `compute_schema_version.py` | 供 `web/vite.config.ts` 注入前端 `__SCHEMA_VERSION__` |
| `tsprune-baseline.txt` | 前端死代码基线（只减不增） |

## 5. 迁移注意（2026-10-31 目录整理）

脚本已从 `scripts/` 根目录迁到分类目录；以下**外部引用**需要手动检查：

- **Windows 任务计划**：`backup_task.bat`、`restore_task.bat`、`sync_openviking_task.bat` 的路径变了，
  请 `schtasks /Change /TN ... /TR "<新路径>"` 或删除后按 README 重新注册；已注册任务不会自动跟随。
- **Claude Code SessionStart hook / 其他本机脚本**：如引用 `scripts/ensure-services.sh`，改为
  `scripts/ops/ensure-services.sh`。
- **文档/代码里的旧路径**：本仓库已统一替换；若你本地还有外部笔记/快捷方式，请按上表更新。
- **OpenViking 增量状态**：`scripts/sync/.sync_openviking_state.json` 里仍是旧路径 key；
  下次同步会把新路径当新文件上传，但**旧路径的远端索引不会自动删除**（脚本只提示 stale）。
  需要干净索引时，可删除该状态文件做一次全量同步，并在 OpenViking 侧清理 `scripts/` 旧条目。

## 6. 维护规则

1. **新脚本先选目录**：不确定时按第 1 节职责判断；不要往 `scripts/` 根目录新增文件。
2. **新增/移动后同步更新**：本索引、`oneoff/README.md` 或 `archive/README.md`、
   `CLAUDE.md` 项目结构（如新增目录）、以及所有引用路径（`rg 'scripts/'` 自查）。
3. **门禁**：维护目录的 Python 脚本必须通过 `scripts/ci/check_scripts.py`；bat 含中文必须 GBK + `chcp 936`；
   ps1 含中文必须 UTF-8 BOM。
4. **归档**：方向结项/脚本完成使命 → 移到 `scripts/archive/` 并登记原因；确认不再复现价值时按
   「删除优先于维护」删除。
5. **服务启停**：脚本只提示，不自动重启；`ops/restart.sh`、`ops/ensure-services.sh` 由用户手动执行。
