# 随机评分页（`/random-rating`）

> **状态**：现行（2026-11-15 按代码盘点）。真源：`web/src/views/RandomRatingView.vue`（329 行）、
> `web/src/composables/useRandomRating.ts`。评分的数据契约见
> [评分功能方案与博主详情应用](评分功能方案与博主详情应用.md)；本文只讲**这个页面怎么用、怎么抽、怎么接键盘**。

## 1. 用途

给素材快速补星的一种"刷"法：一次只出一张图，评完自动换下一张。
适合清理库存（哪些该进垃圾桶）、给头部素材补评分、以及给后续的
「评分排序 / 未评分优先」提供数据。

## 2. 抽样规则（不是完全随机）

| 规则 | 说明 |
| --- | --- |
| 只抽图片 | 视频不参与评分页（`media_type=image`） |
| **优先未评分** | `rating` 为空或 `0` 的素材优先；一批抽完再抽下一批 |
| 抽完回退 | 未评分的抽完了，自动回退到「已评分图片」继续刷（可改评分） |
| 随机 | 走 `GET /api/inspirations?sort=random&media_type=image`，每次取一小页再随机取一张 |

页面顶部会明确当前所处阶段：`待评分 N 张` 或 `已评分图片 N 张`，并显示「本次已评 X 张」。

## 3. 交互（含键盘）

| 操作 | 效果 |
| --- | --- |
| 点星星 / 按 `1`~`5` | 直接给当前图打星，**评完自动换下一张** |
| 清除评分（0 星） | **不自动跳转**——留给用户确认，避免误清后图已经翻页 |
| 空格 / `→` | 换下一张（不评分） |
| `Esc` | 返回素材库；删除确认弹窗打开时按 `Esc` 只关弹窗 |
| 「删除」按钮 | 打开垃圾桶原因弹窗，选原因后**软删除**（可恢复，进负样本时排除 `隐私`） |

键位实现：`onKeydown` 挂在 `window`，`event.repeat` 被忽略（长按不会连打）；
离开页面时清掉「自动换下一张」的计时器与监听。

## 4. 展示细节

- **看原图不打缩略图**：缩略图看不清细节，评分页加载大图（`getFileUrl`），这是刻意的选择；
- 图片下方展示来源、作者、入库时间（`sourceLabel` / `formatDate`）；
- 空态用 `AsyncState`：素材库里没有可评图片时给出「先去上传或采集」的引导；
- 删除原因弹窗复用素材库的 `TrashReasonModal`（同一套枚举与文案）。

## 5. 与其它评分入口的关系

| 入口 | 场景 |
| --- | --- |
| 本页（随机评分） | 无目标地"刷"，补数据 |
| [人物优先评分](人物优先评分.md)（独立页 `/person-rating`） | 按人物排队：已评占比低的博主先评，逐张抽未评分图片；与首页随机评分互补 |
| 素材库网格单张打星 | 浏览时顺手评 |
| 详情页评分 | 看大图时评，**与列表同步**（2026-11-12 修复的缺口） |
| 博主详情「按张」打星 | 针对某个人的作品评（人物组按账号合并计算均分） |

五处写的是同一个字段 `inspirations.rating`，接口同一套（含批量评分接口的字段完整性修复）。

## 6. 常见坑

1. **抽不到图**：素材库全是视频，或都已评分且筛选在"待评分"阶段——看顶部计数。
2. **评完不跳**：评的是 0 星（清除）——按设计不自动跳。
3. **删除后还能看到**：删除是软删（进垃圾桶），垃圾桶里可恢复；随机页只抽在用素材。
4. **评分后排序没变**：`rating` 排序把未评分当 0，需要 `unrated_first` 才会把未评分排前面。
