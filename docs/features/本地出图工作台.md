# 本地出图工作台（前端）

> **状态**：现行（2026-11-15 按代码盘点）。真源：`web/src/views/GenerateView.vue`（631 行）、
> `web/src/components/generate/`（11 个组件）、`web/src/api/generate.ts`、`backend/app/routers/generate.py`。
> **后端怎么调 ComfyUI / 云端模型**见 [ComfyUI出图接入方案](ComfyUI出图接入方案.md) 与
> [豆包Seedream5.0Flash图生图接入](豆包Seedream5.0Flash图生图接入.md)；本文只讲**页面怎么组织、状态怎么流转**。

## 1. 一句话

一个页面走完「选参数 → 生成 → 看候选 → 入库/丢弃 → 翻历史/对比 → 一键轮播」。
页面本身只做编排（631 行），参数表单与历史表各 966 行，都已从视图里拆出去。

## 2. 两条通道，同一套 UI

| 通道 | 出现条件 | 说明 |
| --- | --- | --- |
| 本地 ComfyUI（默认） | 恒有 | 走本机 `127.0.0.1:8188`，不出网 |
| 豆包 Seedream（云端） | `ARK_ENABLED=true` 且配了 `ARK_API_KEY` | 素材图/姿态图会上传到火山引擎，属隐私边界变更，默认关闭 |

档位（本地模型 / 云端模型）由 `useGenerateModelSelection` 统一给出；**未审查版档位没权重时，
「一键出图」按钮直接禁用并给出原因**，不是点了才报错。

## 3. 页面结构与组件分工

```
GenerateView（编排）
├─ GenerateParamForm        左栏：模式/档位/尺寸/数量/提示词/参考图/参数预设（966 行）
├─ GenerateCandidatesPanel  右栏：进度、候选勾选、入库/丢弃（235 行）
├─ GenerateHistoryTable     底部折叠区：历史行、同参重跑、导出、两批对比（966 行）
└─ 弹窗
   ├─ PosePickerModal          从姿势图库挑参考姿势（439 行）
   ├─ ReferencePickerModal     从素材库挑参考图（356 行）
   ├─ ReferenceGalleryModal    已选参考图的大图浏览（157 行）
   ├─ GenerateCompareModal     参考图 ↔ 生成图对比（334 行）
   ├─ GenerateRunCompareModal  两批参数对比（250 行）
   ├─ GenerateImportDialog    入库前确认（244 行）
   └─ QuickPoseBatchPanel     一键出图：399 姿势轮播 + 连续多轮（537 行）
```

交互约定（踩过坑才这么写）：

- **候选勾选与灯箱状态互不影响**：打开灯箱不会改变待入库勾选。
- **环境未就绪给引导，不给假成功**：ComfyUI 没起来但云端就绪时，顶部横幅不显示"就绪"。
- **历史默认收起**：历史只存参数，图在候选区；候选过期被清理后历史仍在，用于同参重跑。

## 4. run 的生命周期（6 个状态）

`GENERATION_STATUSES = ("queued", "running", "waiting_vram", "done", "failed", "cancelled")`

| 状态 | 含义 | 前端表现 |
| --- | --- | --- |
| `queued` | 已建 run，等 worker 认领 | 进度条 0%，可取消 |
| `running` | 正在生成 | 轮询进度（0.5 s 一次） |
| `waiting_vram` | 等显存释放（Ollama 模型可能驻留） | 文案提示"等待显存"，最长 900 s |
| `done` | 至少一张成功 | 展示候选、允许入库 |
| `failed` | 全失败 | 给失败原因，可整批重试 |
| `cancelled` | 用户取消 | 保留已出的候选 |

超时与对账：单张上限 **600 s**（超时主动 interrupt）；`running` 超过 **6 h** 且关联任务已消失/终态 →
启动时对账标 `failed`，避免永久卡在 running。

## 5. 候选 → 入库 / 丢弃

| 动作 | 端点 | 结果 |
| --- | --- | --- |
| 入库 | `POST /api/generate/runs/{id}/confirm` | 选中候选复制到素材库，`source_type='generated'`，记录 `generation_run_id`（可溯源、可同参再生成） |
| 丢弃 | `DELETE /api/generate/runs/{id}` | 删该 run 的候选文件，返回删除数量 |
| 整批重试 | `POST /api/generate/runs/{id}/retry` | 同参数重跑 |
| 单张重生成 | `POST /api/generate/runs/{id}/regenerate` | 只重跑一张（参数不同才用） |
| 自动起名 | `POST /api/generate/runs/{id}/auto-title` | 用模型给批次起标题（历史列表可读性） |
| 清理过期候选 | `POST /api/generate/runs/cleanup` | 未确认候选目录保留 **7 天**（`IMAGE_GEN_KEEP_CANDIDATES_DAYS`） |

**入库不是"移动到素材库"而是复制一份**：候选目录归 run 所有，删 run 不影响已入库素材。

## 6. 一键出图（QuickPoseBatchPanel）

给「批量把姿势套到同一张素材上」用的：

- 姿势来自姿势图库的**性感系 399 张轮播**，每次取下一个未用过的姿势；
- 可选**连续 N 次**：一次排 `N × 每次张数` 张（上限由"剩余姿势数"决定）；
- 运行中可「停止连续出图」，已排的轮次不撤销；
- 完成汇总提示「N 轮 / M 张，结果在候选区与生成历史」。

## 8. 常见坑

1. **历史里找不到图**：历史只存参数，图在候选区；候选过期（7 天）就被清理了，历史行还在。
2. **点"入库"没反应**：入库是异步复制 + 建素材，大图会慢；确认弹窗里的数量要与勾选数一致。
3. **云端档位突然消失**：`ARK_ENABLED` 关闭或没配 key；不是前端 bug。
4. **一直 `waiting_vram`**：Ollama 模型占显存未过期，等它或先跑一次打标任务让它换出。
5. **一键出图按钮灰**：未审查版档位缺权重（看禁用原因文案），不是姿势图库没数据。
