# 浏览器插件（Chrome Extension MV3）说明

> **状态**：现行｜编写日期 2026-11-01｜依据 `browser-extension/` 当前实现
> **定位**：在小红书 / 抖音网页上一键把穿搭图片送进本地素材库；只做「选图 + 转交后端」，不解析平台接口、不碰登录态。
> **边界**：仅 Chrome / Edge（Manifest V3）；仅图片；仅小红书、抖音两个站点。

---

## 1. 安装（加载已解压）

1. 打开 `chrome://extensions`（Edge 为 `edge://extensions`）；
2. 打开右上角「开发者模式」；
3. 点「加载已解压的扩展程序」，选择仓库里的 `browser-extension/` 目录；
4. 固定工具栏图标。安装后无需构建、无打包步骤，改源码后点扩展卡片上的「重新加载」即可。

**前置条件**：本地后端已启动（默认 `http://localhost:18888`），见 [本地运行与排障](../ops/本地运行与排障.md)。

---

## 2. 用户操作

| 入口 | 操作 | 结果 |
| --- | --- | --- |
| 工具栏图标 | 打开 popup → 自动提取当前页图片 → 勾选 → 「采集入库」 | 逐张调用后端入库；成功后可选自动触发 AI 分析 |
| 页面图片右键 | 「保存此图片到素材库」 | 单张入库，用系统通知 + 工具栏角标（✓ / !）反馈 |
| popup 设置 | 后端地址 / 自动分析 / 跳过已采集 | 写入 `chrome.storage.local`，立即生效 |

popup 顶部状态条会显示「已连接 (v<后端版本>)」或「未连接 — 请确认后端已启动」；连接检查走 `GET /api/health`。

## 3. 数据链路

```text
网页 DOM
  │  注入 content-scripts/extract-images.js（每次打开 popup 都重新注入）
  ▼
popup（选图 / 设置）
  │  chrome.runtime.sendMessage
  ▼
service worker ──► POST /api/inspirations/from-url      每张图一次
  │            ──► POST /api/ai/analyze/{id}            自动分析开关打开时
  │            ──► GET  /api/inspirations/check-platform-id
  │            ──► POST /api/scraper/extension-tasks     每次采集会话一条
  │            ──► POST /api/scraper/extension-tasks/{id}/complete
  ▼
本地后端（下载图片、去重、缩略图、入库）
```

### 3.1 为什么由后端下载图片

插件**不在扩展内 fetch 平台 CDN 图片**：小红书 / 抖音 CDN 域名不在 `host_permissions` 内，跨域会被浏览器直接拦掉。插件只把图片 URL 交给后端，由后端按 URL 下载——这样也复用了后端已有的 `from-url` 校验、去重与缩略图链路。

### 3.2 同笔记多图与平台 ID

- 平台笔记 ID 在库内受**部分唯一索引**约束（软删除后释放），一张笔记只能对应一条素材；
- 因此批量采集时**只有第一张**携带 `source_platform_id`，其余不传，否则第 2 张起会全部 409；
- 上传前用 `check-platform-id` 查询整页，已入库的图片在 popup 里标「已采集」，`skipDuplicates` 开启时不可选中。

### 3.3 采集会话任务

每次 popup 批量采集或右键采集都会先创建一个 `extension-tasks` 记录（类型归于采集任务），上传结束后上报 `items_found` / `items_added`。任务记录创建失败不影响入库主流程，只在扩展控制台留日志。

## 4. 设置项

存储于 `chrome.storage.local`，popup 与 service worker 共用：

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `apiUrl` | `http://localhost:18888` | 后端地址。**只能填 manifest `host_permissions` 已声明的地址**（默认仅 localhost / 127.0.0.1）；改局域网 IP 需同步改 manifest 并重新加载扩展 |
| `autoAnalyze` | `true` | 入库成功后调 `POST /api/ai/analyze/{id}`；仅图片，视频会跳过 |
| `skipDuplicates` | `true` | 已采集图片标灰且不可选 |

> 插件不发送 `X-API-Key`。默认走回环地址，后端中间件放行；若后端改为非回环监听并启用密钥，插件不会自动适配，需要另行扩展（当前无此需求）。

## 5. 文件结构与职责

| 文件 | 职责 |
| --- | --- |
| `manifest.json` | MV3 清单：权限、host_permissions、popup、service worker、内容脚本匹配规则 |
| `background/service-worker.js` | 设置读写、上传、AI 触发、查重、采集会话任务、右键菜单、通知与角标 |
| `content-scripts/extract-images.js` | 页面内提取图片与元数据（平台识别、懒加载、过滤、去重） |
| `popup/popup.html / popup.js / popup.css` | 选图网格、设置面板、连接状态、上传进度 |

**权限说明**：

- `activeTab` / `scripting`：向当前页注入提取脚本；
- `storage`：保存设置；
- `contextMenus`：右键「保存此图片」；
- `notifications`：右键采集结果没有 popup，需要独立反馈；
- `host_permissions`：后端（localhost:18888）+ 小红书 / 抖音及其图片 CDN（仅用于预览与页面注入）。

## 6. 图片提取规则

目标：只把「内容图」交给用户，避免头像、图标、广告横幅混进来。

1. **平台识别**：`location.hostname` 含 `xiaohongshu.com` / `douyin.com`，否则 popup 提示先打开支持的站点；
2. **URL 解析（兼容懒加载）**：依次尝试 `currentSrc` / `src` → `data-src` → `data-lazy-src` → `data-original` → `data-srcset` → `srcset`（`srcset` 取分辨率最高的一张）；
3. **排除非内容图**：URL 或最近 6 层祖先的 class/id 命中 `avatar|icon|logo|emoji|badge|qrcode|default_head` 即排除（头像原图可能很大，不能只靠尺寸）；
4. **尺寸过滤**：已加载图要求 ≥120×120、宽高比在 0.25~4、且排除 <240×240 的 1:1 小方图；未加载但有懒加载源的图片放行（Chrome 给无 src 的 img 约 80×21 占位尺寸，按尺寸过滤会误杀）；
5. **去重**：去掉 URL 的 `_数字x数字` 尺寸后缀与 query 后分组，同图多尺寸保留尺寸最大的一张；
6. **平台 ID**：小红书匹配 `/explore|discovery/item|note/{id}`，抖音匹配 `/video/{id}` 或 `/note/{id}`；
7. **元数据**：平台、笔记 ID、页面 URL、作者（小红书 `.username` 等，抖音 `[data-e2e="user-info"] .name`）。

## 7. 开发与调试

- **改完代码**：`chrome://extensions` → 扩展卡片「重新加载」；popup 关闭重开；
- **service worker 日志**：扩展卡片点「Service Worker」→ Console；
- **内容脚本日志**：在页面 DevTools Console 里看 `[穿搭采集器] ...`；
- **popup 调试**：右键 popup →「检查」；
- **接口联调**：先 `curl http://localhost:18888/api/health`，再看 popup 顶部状态条。

## 8. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 一直显示「未连接」 | 后端未启动 / 端口不是 18888 / `apiUrl` 写错 | 启动后端；设置面板核对地址；`curl /api/health` |
| 提示「请先打开小红书或抖音」 | 当前标签页不是支持站点 | 切到笔记页再开 popup |
| 提取不到图片 | 页面未加载完、懒加载未触发、或图片被过滤规则误杀 | 向下滚动触发加载后重开 popup；必要时在 Console 看提取数量 |
| 预览图裂开 | CDN 防盗链（扩展页 Referer 被拒） | 已用 `referrerpolicy="no-referrer"`；仍裂说明 URL 失效，不影响后端下载 |
| 「已采集」图片点不动 | `skipDuplicates` 开启 | 设置里关掉「跳过已采集」，或直接刷新列表 |
| 批量只有第一张成功、其余 409 | 平台笔记 ID 唯一约束 | 正常行为；同笔记多图只关联首图，其余素材仍入库 |
| 右键菜单不见了 | 扩展更新 / profile 异常 | 重新加载扩展（Service Worker 每次唤醒都会重建菜单） |
| 修改 `apiUrl` 为局域网 IP 后全部失败 | manifest `host_permissions` 未包含该地址 | 在 `manifest.json` 增加 `http://<IP>:18888/*` 后重新加载 |

## 9. 已知边界 / 不做的事

- **不做平台接口逆向**：只读页面 DOM，不调小红书 / 抖音私有 API，不处理登录态；
- **不做视频**：视频笔记提取到的是封面 / 图集图片，视频本身走 f2 通道；
- **不做自动翻页 / 批量笔记**：一次只处理当前页面；
- **不内置代理 / 换 IP**：采集合规要求见 CLAUDE.md「安全与数据合规」；
- **不发布到商店**：本地加载已解压扩展，无签名、无自动更新。
