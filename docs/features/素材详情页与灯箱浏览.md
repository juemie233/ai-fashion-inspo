# 素材详情页与灯箱浏览

> **状态**：现行（2026-11-22 按代码核对）。真源：`web/src/views/DetailView.vue`（770 行）、
> `components/inspiration/{DetailMediaPane,DetailInfoPanel,SimilarSection,ImageLightbox,
> VideoKeyframes,ImageCropModal,TagCorrectionModal,DetailTrashModal}.vue`、
> `composables/{useBrowseContext,useSimilarItems,useOutfitTags}.ts`。

## 1. 一句话

详情页是「在上下文中看一张图」的地方：左栏看（图/视频/灯箱），右栏改（评分/收藏/标签/合集/删除），
`←` `→` 连续刷图，下方给相似素材。

路由：`/detail/:id`（`name: 'detail'`），来源可以是首页、搜索结果、合集、裁剪结果页等，
**进入时带的 query 决定「上一张/下一张」的顺序**。

## 2. 左右两栏的分工

| 组件 | 内容 |
|---|---|
| `DetailMediaPane`（左） | 图片大图 + **灯箱** + 裁剪入口；视频则播放 + **关键帧条带**（`VideoKeyframes`） |
| `DetailInfoPanel`（右） | 操作按钮、基本信息（来源/作者/时间/评分）、关联人物、大标签、标签分组 |
| `SimilarSection`（下） | 相似素材（向量近邻） |

两栏都是**从 DetailView 模板原样抽出的提取式重构**：数据与动作走 props/emit，
**视图仍是唯一的状态持有者**（穿搭大标签、相似推荐这两个 composable 也在视图侧）。
所以改交互时优先在 `DetailView` 里接线，而不是让子组件自己发请求。

## 3. 上一张 / 下一张（`useBrowseContext`）

- 从**进入详情时携带的列表筛选 query** 重建「同一次浏览」的相邻素材，不需要回列表就能连续刷；
- 当前素材**不在上下文列表里**时（比如从消息/外链直达），导航按钮直接隐藏，而不是给个错的相邻项；
- 键盘 `←` / `→` 触发，**保护条件很全**：`INPUT` / `TEXTAREA` / `contentEditable` 聚焦时、
  灯箱打开时、垃圾桶弹窗/裁剪弹窗打开时，方向键都交还给用户（不会一边填标签一边翻页）；
- 顺序由 `buildBrowseParams()` 保证与列表页一致（筛选+排序同源），详见
  [素材库首页与批量操作](素材库首页与批量操作.md) §3。

## 4. 能改什么

| 动作 | 入口 | 说明 |
|---|---|---|
| 评分 | 右栏星级 | 写同一个 `rating` 字段，与列表/随机评分页同步 |
| 收藏 / 取消 | 右栏按钮 | 即时生效 |
| 加入合集 | `CollectionPickerModal` | 合集是两级结构，加入后可再整理 |
| 增删标签 | 大标签 + 标签分组 | 手改标签会标记来源，参与后续治理统计 |
| 标签纠错 | `TagCorrectionModal` | 「标错了 / 漏标了」落 `tag_corrections`，供质量看板统计 |
| 裁剪 | `ImageCropModal` | 单张手动裁剪（与「手机截图自动裁剪」的批量链路不同） |
| 移入垃圾桶 | `DetailTrashModal` | 选原因后软删；在垃圾桶内打开会显示「此素材在垃圾桶中」 |
| 相似素材批量加大标签 | `SimilarSection` | 把相似的一批一起打同一个大标签 |

## 5. 两个出图入口（容易混）

右栏有两个按钮，都跳到出图页但档位不同：

| 按钮 | 行为 |
|---|---|
| 「把这张图作为参考」 | 跳出图页，切到 **Qwen-Image 2.1 未审查版**，并把素材 ID 填进「参考素材 ID」 |
| 「换姿势」 | 跳出图页，默认走**云端换姿势**（Seedream），进入后选姿态（**默认不预选**） |

前者是图生图的参考图，后者是「素材图 + 姿态图」的组合，别指望它们共享参数。

## 6. 视频素材在详情页

- 播放器 + 关键帧条带（`VideoKeyframes` 调 `GET /api/files/keyframes/{id}`，首次访问会**懒提取**，
  可能等几百毫秒）；
- 没有缩略图条通常是 ffmpeg 不可用（静默降级），详见
  [视频素材处理链路](视频素材处理链路.md) §4.2。

## 7. 常见坑

1. **`←` `→` 没反应**：三种情况——当前素材不在浏览上下文里（导航被隐藏）、有弹窗/灯箱开着、
   正在输入框里打字。三者都是刻意设计，不是坏了。
2. **从别处直达详情，没有上下张**：没有列表 query 就没有上下文；从素材库点进来才有。
3. **改了标签回到列表没变**：列表状态在 `stores/inspirations` 里，详情页改完会更新缓存项；
   若用浏览器后退回到旧页面快照，需要刷新。
4. **相似素材为空**：向量未生成或任务在跑；相似推荐走向量近邻，不走向量就没有结果。
5. **裁剪后图片变了，缩略图还是旧的**：缩略图有独立缓存，`ImageCropModal` 会重建；
   如果看到的还是旧图，先硬刷新（浏览器缓存按 URL 命中）。
