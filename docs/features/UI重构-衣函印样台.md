# UI 重构：衣函 · 印样台

> 状态：第一阶段（设计系统 + 外壳 + 核心页面）已提交 `1e250ed`；第二阶段（剩余页面 + 跨页收尾）已完成，待提交。
> 设计技能：`deepseek-frontend-design` + `frontend-design`。本文记录设计方向、tokens、页面覆盖、验证方式与剩余边界，方便后续维护者按同一套语言扩展。

## 1. 设计方向

**衣函 · 印样台**：本地 AI 穿搭素材库 = 个人时装档案室，界面是审阅样张的「印样台」，不是 SaaS 卡片墙。

- 取自制片厂的接触印样（contact sheet）：样张之间只有 1px 墨线、零圆角、零阴影；说明区是一行手写标签式的来源/作者/标签。
- 取自已故档案室/索引卡：左侧「索引脊」是信息架构（浏览/管理分组 + 朱砂书签线），内容顶部一行 running head 显示当前页面与实时同步状态。
- 数字用 Georgia 老式数字（tabular-nums）承担计数/评分/日期/名次，形成「档案编号」的阅读语气；中文用系统无衬线承担界面与正文。
- 唯一记忆点：**朱砂裁切标记**——收藏/批量选中的样张四角出现角线（素材网格、详情大图、上传投递口同一语言），其余时候低调得像一张印刷面。

自审（技能要求）：把计划套到「任意图片库」上会成立的是「图片网格」；不成立的是 Georgia 档案数字、松烟绿+朱砂印章色、裁切标记的「留版」语义、索引脊 + running head。因此删掉了圆角卡片堆、悬停上浮、彩色胶囊、emoji 图标、01/02/03 装饰与 A·B·C 元信息行。

## 2. Design tokens

唯一真源：`web/src/styles/arco-theme.css`（CSS 变量）。页面/组件只引用变量，不写死颜色；动效、圆角、字阶同理。

| 类型 | 值 |
| --- | --- |
| 纸面 | `--paper #EFEDE6`、`--sheet #FAF9F4`、`--sheet-2 #F4F2EA` |
| 墨色 | `--ink #1C201E`、`--ink-2 #4F534D`、`--ink-3 #686C64`、`--line #D9D7CD`、`--line-strong #B9B8AD` |
| 主操作 | `--pine #2E4B40`、`--pine-deep #22382F`、`--pine-soft #E5EAE3` |
| 状态色 | `--seal #A6402F`（收藏/选中/危险）、`--jade #3F6B57`（成功/在线）、`--amber #8A6A2F`（警告） |
| 字体 | 中文系统无衬线栈 `--font-sans`；数字/拉丁 `--font-numeric`（Georgia 老式数字），无 webfont |
| 字阶 | 12 / 13 / 14 / 16 / 20 / 28 / 32 / 40（正文 16、行高 1.8） |
| 间距 | 页面级 4/8 栅格（8/16/24/32/48）；控件内部 2–6px 印刷线对齐；36/44 为触控常量 |
| 圆角 | `--radius-sm 2px` / `--radius-md 3px` / `--radius-lg 5px`；不用大圆角卡片 |
| 动效 | 仅状态反馈 120ms；无逐区块 fade-up/悬停上浮；全局 `prefers-reduced-motion` 关断 |

注意：Arco 在 `body` 上重复声明了自己的蓝色彩板（`:root` 覆盖不到），因此 `arco-theme.css` 末尾把同一套变量在 `body` 层再声明一次；遗漏会表现为「禁用态主按钮、浅色边框、语义标签仍回落到 Arco 默认蓝」。图表 canvas 不认 CSS 变量，`components/chart/ArcoChart.vue` 里维护了一份同值 hex 色板。

## 3. 外壳与页面覆盖

外壳（第一阶段）：`components/layout/AppLayout.vue`

- 左侧 216px「索引脊」：朱砂方章「衣」+「穿搭档案 / 本地工作台」+ 浏览/管理分组 + 选中朱砂书签线；≤1024px 收成 64px 图标脊（菜单项 44px，满足触控）。
- 内容区顶部 44px running head：`穿搭档案 / 当前页` + 实时同步/轮询降级 + 本地·单机；吸顶、纯纸面底（无毛玻璃）。
- `.main-content` 仍是唯一滚动容器，保留 `e2e/ipad.spec.ts` 依赖的固定外壳语义。

## 4. 跨页收尾实现要点

- **图表**：`ArcoChart.vue` 统一注入色板、字体、坐标轴轴线/标签、分栏虚线、tooltip/legend 墨色；消费方未显式配色时自动生效，显式设置了颜色的序列保留其语义色（已把各图表的 ECharts 默认高饱和色映射到印样台色板）。
- **硬编码色**：批量把 scoped CSS 与内联 style 里的中性灰/浅底/圆角替换为 tokens（`#999 → var(--ink-3)`、`#f5f5f5 → var(--sheet-2)`、`border-radius: 8px → var(--radius-md)` 等）；脚本内联颜色按用途区分处理：DOM 样式用 `var(--token)`，ECharts canvas 用同值 hex。
- **emoji 图标**：清理第二阶段目录与公共组件里作为图标的 emoji（保留 ✓ ✗ ★ ☆ ♥ 与箭头等排版符号）；纯图标槽位换成有信息的文字（如合集类型「智/集」、封面缺省「暂无封面」、置顶「置顶/已置顶」、人物头像缺省取名字首字）。
- **空态/表格/弹层**：全局统一空态插图去饱和、折叠面板/描述列表/表单标签纸面墨线、表格表头纸色+行线、弹层印刷偏移影+方角。
- **响应式**：沿用第一阶段断点（≤1024 图标脊、≤767 单列/横滑、44/36 触控下限）；本阶段补了 375 下 Arco Space 换行、合集左栏堆叠、任务描述表横向滚动、评分操作行换行等。

## 6. 已知边界与后续

- `web/src/utils/taskPresentation.ts`、`composables/useNotification.ts` 等工具/composable 里仍有 `⚠` 前缀（部分会进入提示文案），不在本轮写入域；
- `/models` 的任务类型标签、图表图例等语义色仍以文字/色块区分，未做统一的「档案编号」排版；
- 深色模式未实现（当前 tokens 只有纸面浅色一套）；
- 部分深度弹窗（如采集漏斗、分析对比）只做了颜色与圆角 token 化，未重排信息层级；
- 新增页面接入方式：`h2.page-title` + `.subtitle`、优先用 `--sheet/--ink/--pine/--seal` tokens 与 `ArcoChart`，不要再写死色值与 8px+ 圆角。
