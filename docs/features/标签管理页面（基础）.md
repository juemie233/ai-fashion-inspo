# 标签管理页面（基础，`/tags`）

> **状态**：现行（2026-11-22 按代码核对）。真源：`web/src/views/TagManageView.vue`（515 行）、
> `components/tag/`（15 个组件）、`composables/useTagManage.ts`、`composables/useSplitResize.ts`、
> `api/tags.ts`。深度治理页见 [高级标签管理页面](高级标签管理页面.md)；
> 标签体系与打标链路见 [AI分析与标签治理](AI分析与标签治理.md)。

## 1. 两个标签页面的分工

| 页面 | 路由 | 定位 | 典型操作 |
|---|---|---|---|
| **基础页（本文）** | `/tags` | 日常维护：把标签整理干净 | 浏览分组、置顶、拖拽排序、改名/改类别、别名合并、导入导出、重复扫描 |
| 高级页 | `/tags/advanced` | 深度治理：找问题、批量加工 | 健康度扫描、自动聚类、网络图、正则批量编辑、历史回滚、层级树、效果分析 |

判断标准：**只改某个标签本身 → 基础页；要跑扫描/算法/批量规则 → 高级页**。

## 2. 页面布局

```
TagStatsBar（标签总数/分组数/未使用数等概览）
TagToolbar（搜索、新建、导入、导出、批量、扫描重复、分析入口）
├─ 左：TagGroupList（分组折叠列表，可拖拽）
└─ 右：TagInspirationGrid（当前选中标签的素材预览）+ TagInsightCard（该标签的洞察卡）
```

左右分栏支持拖拽调整比例（`useSplitResize`），比例写入本地偏好。

## 3. 能力清单

| 能力 | 组件 / 接口 | 说明 |
|---|---|---|
| 分组浏览与折叠 | `TagGroupList` | 按类别分组，来源与使用次数直接显示在行内 |
| 搜索 | `TagToolbar` | 标签名模糊搜索，筛选时拖拽排序自动退出 |
| 置顶 | `TagGroupList` → `pinned` | 置顶标签由后端固定在前，**不参与自定义排序** |
| 自定义排序 | `TagGroupList` | 拖拽写 `sort_order`；触屏设备用「上移/下移」按钮替代拖拽 |
| 拖拽改类别 | `TagGroupList` | 跨分组拖动即改 `category`，与改排序共用一套拖拽状态 |
| 新建 / 编辑 | `TagCreateForm` / `TagEditModal` | 名称、类别、备注（`description`） |
| 别名归一 | `TagAliasModal` | 同义词归到同一标签，别名参与搜索与打标匹配 |
| 合并 | `TagMergeModal` / `TagBatchMergeModal` | 合并后关联素材重指向、别名一并迁移 |
| 批量编辑 | `TagBatchEditModal` | 批量改类别 / 重命名（正则批量规则在高级页） |
| 删除 | `TagGroupList` | 物理删除（标签表无软删除），会解除与素材的关联 |
| 重复扫描 | `TagDuplicatesPanel` + `TagDuplicateCompareModal` | 名称相似/归一化后相同的标签两两对比，人工决定合并与否 |
| 导入 / 导出 | `TagImportModal` / `exportTags` | 导出标签清单（含类别、别名、次数）用于备份或迁移 |
| 使用趋势与共现 | `TagAnalyticsModal` | 趋势曲线 + 共现关系图（这个标签常和谁一起出现） |
| 素材预览 | `TagInspirationGrid` | 选中标签即看打到它的素材，点开进详情 |

## 4. 前端结构

- `TagManageView` 只做编排（515 行）：15 个组件 + 一个 `useTagManage` +
  `activeModal` 单例状态（`ModalName` 联合类型，保证同一时刻只开一个弹窗）；
- `useTagManage` 承担「列表 + 分组 + 选中标签 + 统计」的状态与请求，视图不直接调 API；
- 组件按域放在 `components/tag/`，props + emit 通信；高级页的 7 个面板在
  `components/tag/advanced/` 下，两页互不复用弹窗。

## 5. 与打标链路的关系

- 打标时新标签走 `get_or_create_tag()`（大小写/别名归一在服务层，不在本页）；
- 本页删除标签不会删素材，只解关联——所以「删标签」比「删素材」安全，别被确认弹窗吓到；
- 改标签名会**同时影响历史素材的显示**（关联表按 ID 关联），这是有意设计：名字是标签的属性，不是素材的属性。

## 6. 常见坑

1. **筛选状态下拖不动**：搜索/筛选激活时拖拽被禁用（排序结果和筛选结果混在一起会写乱 `sort_order`）。
2. **置顶标签拖不走**：置顶由后端排序规则固定在前，取消置顶后才能拖到自定义位置。
3. **合并后找不到旧标签**：合并不保留「被合并标签」作为别名时，它就从列表里消失了；
   想保留搜索命中就选「迁移为别名」。
4. **删标签后素材少了一批筛选结果**：素材还在，只是不再带这个标签；用素材库按来源/时间找回。
5. **导入后出现近似重复**：导入不去重（按名称精确匹配），导入完跑一次「重复扫描」再合并。
