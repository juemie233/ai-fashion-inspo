# 数据治理与数据洞察（两个后台页面）

> **状态**：现行（2026-11-15 按代码盘点）。真源：`web/src/views/GovernanceView.vue`（349 行）、
> `views/InsightsView.vue`（94 行）、`components/admin/`、`backend/app/routers/admin.py`、
> `services/admin_stats_service.py`、`services/ai_dashboard_service.py`。

## 1. 先分清这两页在解决什么

| 页面 | 解决的问题 | 典型动作 | 主色调 |
| --- | --- | --- | --- |
| **数据治理**（`/admin/governance`） | 「数据坏了 / 脏了，怎么修」 | 删孤立文件、去重、找近似重复、批量清无标签 | 破坏性 |
| **数据洞察**（`/admin/insights`） | 「数据长什么样、质量怎么样」 | 看向量覆盖率、导出报表、看趋势、比提示词版本 | 只读 |

两页都挂在「管理」菜单下，路由 name 分别是 `admin-governance` / `admin-insights`。
**破坏性动作（批量删除、清理孤儿、去重）都要求 API Key**（后端 `Depends(require_api_key)`）。

## 2. 数据治理：四个页签

| 页签 | 组件 | 做什么 | 端点 |
| --- | --- | --- | --- |
| 批量清理 | `AdminProblemCards` + `AdminTaskProgress` | 两个问题卡片（**无标签素材** / **分析失败素材**）各自的批量删除入口；删除走任务队列，进度用全局任务条展示 | `GET /api/admin/stats`、`POST /api/admin/batch-delete`、`POST /api/admin/batch-unmark-ai` |
| 数据完整性 | `AdminIntegrityCheck` | 比对「库」与「盘」：库里有但盘上没有（缺文件）、盘上有但库里没有（孤立文件） | `GET /api/admin/integrity-check`、`POST /api/admin/cleanup-orphans` |
| 重复文件 | `AdminDuplicates` | **SHA-256 完全相同**的精确重复；一键去重 | `GET /api/admin/find-duplicates`、`POST /api/admin/deduplicate`、`GET /api/admin/check-duplicate` |
| 近似重复 | `AdminNearDuplicates` | 字节不同但视觉相似（pHash ≤ 阈值），**只给候选、人工并排预览后确认** | `POST /api/admin/near-duplicates`、`POST /api/admin/phash-backfill` |

### 2.1 批量清理的语义

- 卡片上的两个数字来自 `stats`：`untagged_count`、`analysis_failed_count`。
- 删除是**不可撤销**的（确认弹窗原话「此操作不可撤销」），走 `batch-delete` 创建任务：
  请求体 `{"condition": "untagged" | "analysis_failed"}` 或 `{"ids": [...]}`。
- 按 ID 删与按条件删在 **API 层解析成同一份 ID 列表**，保证删除语义稳定（不会因为前端筛选变化而误删）。

### 2.2 孤儿文件（最容易误删的一块）

`integrity-check` 只报告，不删。`cleanup-orphans` 才是删，且有三道保护：

1. **`dry_run=true` 先预览**：给出将删除数量、体积、样本路径，确认后再执行；
2. **10 分钟保护期**：刚写入、尚未落库的文件不会被判成孤儿（避免误删正在入库的文件）；
3. **判定范围包含垃圾桶行**：只查「未删除素材」会把所有垃圾桶文件误判为孤儿（2026-11-11 实测踩过），
   现在凡是「库里有记录（含垃圾桶）引用」的文件都不算孤儿。

### 2.3 精确重复 vs 近似重复

| | 精确重复 | 近似重复 |
| --- | --- | --- |
| 判定 | 文件内容 SHA-256 相同 | pHash 汉明距离 ≤ 阈值（默认 32） |
| 去重动作 | 每组**保留评分最高**的 1 个，其余**物理删除**（任务队列） | 只返回候选，**不自动删**，人工确认 |
| 适用 | 同一张图重复入库 | 不同压缩/缩放/水印的同一画面 |

> 去重是**物理删除**而不是进垃圾桶：重复件进垃圾桶会污染负样本。

## 3. 数据洞察：三个页签

| 页签 | 组件 | 内容 | 端点 |
| --- | --- | --- | --- |
| 向量管理 | `AdminVectorPanel` | 文本/图像两个向量表的覆盖率、缺口数量、一键回填（可只补缺失） | `GET /api/admin/vector-stats`、`POST /api/admin/vector-backfill` |
| 数据报表 | `AdminExportPanel` + `AdminTrendChart` + `AdminPersonFrequency` + `AdminAuditLog` | 导出 CSV（UTF-8 BOM，Excel 直接打开）、按天入库趋势、高频人物排行、破坏性操作审计日志 | `GET /api/admin/export`、`/trend`、`/person-frequency`、`/audit-logs` |
| 提示词质量 | `AdminPromptQuality` | 按 **`prompt_version`**（提示词内容哈希前 8 位）聚合打标质量指标，用于比较不同提示词版本的效果 | `ai_dashboard_service` 的聚合接口 |

提示词版本的可读名来自仓库根的 `prompt_versions.json`（哈希 → 人读标签），所以看板不必显示裸哈希；
历史版本的记录不再变化时可以直接对照。

## 4. 口径与边界

| 概念 | 定义 | 注意 |
| --- | --- | --- |
| 缺文件 | 库里有行，磁盘没有文件 | 先查存储盘/`STORAGE_ROOT` 是否挂对，再考虑修复 |
| 孤立文件 | 磁盘有文件，库里无任何行（**含垃圾桶行**）引用 | 有 10 分钟保护期；先 dry-run |
| 精确重复 | 内容 SHA-256 相同 | 去重后物理删除，不可恢复 |
| 近似重复 | pHash 距离在阈值内 | 只给候选；冷缓存时结果不完整但不报错 |
| 向量覆盖率 | 有向量的素材 / 可编码素材 | 视频按关键帧编码，覆盖率口径与图片不同 |
| 审计日志 | `audit_logs` 表 | 删除/去重/清空垃圾桶等破坏性动作才写 |

## 5. 常见坑

1. **在治理页点了删除，素材却出现在垃圾桶**：批量删除走的是 `batch-delete`（物理删）；
   若你看到的是垃圾桶里有，那是别的路径（素材库的单条/批量移入垃圾桶）。
2. **孤儿文件清理完，缩略图还 404**：缩略图路径与主文件路径都参与判定，可能只清了其中一个——
   重新跑一次 `integrity-check` 看剩余项。
3. **去重把一个高分素材删了**：保留规则是「每组保留评分最高」，同分时按内部顺序取第一个；
   重要素材先手动评分再跑去重。
4. **近似重复扫描"不完整"**：缓存未就绪，先 `phash-backfill` 再扫（详见
   [搜索与向量检索](搜索与向量检索.md) §5）。
5. **看板数字与素材库对不上**：洞察页多数指标默认排除垃圾桶；素材库首页的总数含不同筛选条件，
   对比前先确认口径（页面上都有对应说明）。
