# 上传素材与入库前处理（`/upload` 页）

> **状态**：现行（2026-11-15 按代码盘点）。真源：`web/src/views/UploadView.vue`（560 行）、
> `components/upload/`（4 个组件）、`composables/useUploadPrefs.ts`、`constants/upload.ts`、
> `backend/app/routers/inspirations.py` 的 `POST /api/inspirations` 与 `/from-url`。
> 入库之后的生命周期见 [素材生命周期与垃圾桶](素材生命周期与垃圾桶.md)。

## 1. 一句话

「拖进来 → 看队列 → 一键上传」：本地文件直传后端，每个文件独立状态；
**去重在客户端先拦一道、服务端再拦一道**；上传成功后可选自动触发 AI 分析。

## 2. 五个入口

| 入口 | 说明 |
| --- | --- |
| 拖拽 | 整个窗口接收 drop |
| 剪贴板粘贴 | `Ctrl+V` 粘贴截图/复制的图片（只收 `image/*`） |
| 选择文件 | 常规文件选择器（可多选） |
| 导入文件夹 | `<input webkitdirectory>`，一次选中整个目录（**不递归子目录之外的东西**） |
| URL 导入 | 直接给图片地址，走后端 `POST /api/inspirations/from-url` |

支持扩展名：`.jpg .jpeg .png .webp .gif .bmp .mp4`。
**队列上限 1500**（`constants/upload.ts` 的 `MAX_UPLOAD_QUEUE_SIZE`，视图与页面文案共用同一常量，
历史上文案与常量曾各自写死 500，已收敛）；超出按剩余容量截断并提示「仅保留前 N 个」。

## 3. 队列模型

| 状态 | 含义 |
| --- | --- |
| `pending` | 等待上传 |
| `uploading` | 正在上传（带单文件进度） |
| `done` | 成功，记下 `resultId` |
| `duplicate` | 被去重拦截，文案「文件已存在」 |
| `failed` | 失败，附错误原因；可移除或重试 |

- 上传是**串行**的（一个接一个），大文件在场时后面的会等；
- 支持中途「停止上传」（已完成的不会回滚）；
- 视频条目可直接点开预览（模态框），不需要先上传。

## 4. 去重（两道闸）

1. **客户端**：同一批队列内按内容哈希缓存（`_dedupHashes`），同批里重复的文件直接标 `duplicate`，
   不再发请求；跨批则调 `GET /api/admin/check-duplicate?hash=...` 查已入库。
2. **服务端**：入库时按内容 SHA-256 再判一次（`inspiration_dedupe`），并受
   「部分唯一索引 `ix_inspirations_source_platform_id`（`WHERE deleted_at IS NULL`）」约束。

> 差距点：客户端去重只看**在用**素材；垃圾桶里的同一文件不会被客户端拦，
> 但服务端入库路径与采集路径的判重口径不同（采集有 URL 墓碑），上传仍可能重新入库——
> 这是刻意的（垃圾桶素材不能作为"已存在"的依据）。

## 5. 上传选项（`UploadOptionsPanel`）

| 选项 | 作用 | 默认 |
| --- | --- | --- |
| 来源作者 | 写进 `source_author` | 空 |
| 快速标签 | 上传成功后追加这批标签（`addTagsToInspiration`，失败只计数不阻断） | 无 |
| 自动 AI 分析 | 每个文件成功后 `POST /api/ai/analyze/{id}`（**异步触发，不等结果**） | 开 |
| 跳过重复 | 开启客户端去重；关掉则全部上传（服务端仍会拦） | 开 |
| 绑定博主 | 上传成功后关联到选定博主（幂等，失败只提示） | 无 |
| 上传后跳转 | 全部完成后是否跳转到素材库 | 可配 |

这些偏好用 `useUploadPrefs` 持久化（localStorage），下次进页面沿用。

## 6. 入库时后端做了什么

| 步骤 | 说明 |
| --- | --- |
| 校验 | 扩展名 + 真实格式（`validate_media`）+ 大小上限（`MAX_IMAGE_UPLOAD_MB` / `MAX_VIDEO_UPLOAD_MB`） |
| 落盘 | 原图进 `storage/images/`，缩略图进 `storage/thumbnails/`；视频抽关键帧 |
| 写库 | `source_type='manual_upload'`、`content_hash`、`created_at`（naive UTC，输出带 Z） |
| 质量预检 | 尺寸过小/近乎纯色/极端比例可直接拒（`quality_precheck_enabled`） |
| 自动通过 | `manual_upload_auto_approve=true` 时跳过人工审核直接 approved；否则进待审核 |
| 标签 | 上传页的快速标签在**上传后**单独追加，不在同一次事务里 |

## 7. URL 导入的差异

`POST /api/inspirations/from-url` 由后端下载图片再入库，与本地文件路径的区别：
没有客户端去重（直接进服务端判重）、`source_url` 有值（后续采集判重靠它）、
失败原因在响应里（下载失败/CORS 限制/格式不识别）。

## 8. 最近上传

`RecentUploads` 用 `sessionStorage` 记本次会话上传成功的缩略图，
点击直接跳详情——**会话结束就清空**，不是历史记录；要查全部请去素材库筛选「手动上传」。

## 9. 常见坑

1. **拖了 500 个只进来一部分**：队列上限 1500 之外按剩余容量截断；分批上传。
2. **明明没传过却提示"文件已存在"**：内容哈希相同（同一张图不同文件名也算重复）；关掉「跳过重复」可强制上传。
3. **上传成功但没标签**：自动分析是**异步触发**，等分析任务跑完；或检查活跃模型是否可用。
4. **视频没有缩略图**：关键帧提取依赖 ffmpeg，未装或超时会回退占位图。
5. **上传大图失败 413**：超过 `MAX_IMAGE_UPLOAD_MB`（默认见 [配置项参考](../overview/配置项参考.md)）。
