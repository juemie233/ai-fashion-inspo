# 收藏增强 P0：收藏时间 / 收藏历史 / 收藏中心 / 合集内容搜索

> **状态**：现行（2026-11-19 实施）
> **范围**：后端 P0（A 收藏时间与事件流水、B 收藏中心数据接口、C 合集内容搜索筛选排序）。
> 前端页面由并行任务实现，本文只描述后端契约与口径。

## 1. 目的

旧版本收藏只有一个布尔 `is_favorite`：

- 不知道「什么时候收藏的」→ 无法按收藏时间排序，也无法做「最近收藏」；
- 收藏/取消没有留痕 → 没有收藏历史可追溯；
- 收藏中心（总数/本周新增/未评分/未整理/最近动态）没有数据来源；
- 合集内容只能按固定顺序翻，不能搜索/筛选/排序。

本次 P0 补齐上述能力，不新增任务、不改采集/评分/质量链路。

## 2. 数据模型

### 2.1 `inspirations.favorited_at`

| 项 | 说明 |
| --- | --- |
| 类型 | `DateTime`，可空（UTC naive；输出经 `format_utc` 带 `Z` 后缀） |
| 语义 | 最近一次**收藏**的时刻；取消收藏清空为 NULL |
| 索引 | `ix_inspirations_favorite_time`：`(is_favorite, deleted_at, favorited_at, id) WHERE is_favorite = 1`（部分索引只覆盖收藏行） |
| 迁移回填 | 历史数据没有真实收藏时间，用 `updated_at` 回填（**近似值**，可能晚于真实收藏时刻）；只回填当前仍是收藏状态的行 |

### 2.2 `favorite_events`（新表）

| 列 | 说明 |
| --- | --- |
| `id` | 自增整数主键 |
| `inspiration_id` | `inspirations.id` 外键，`ON DELETE CASCADE` |
| `action` | `favorite` / `unfavorite` |
| `source` | `web`（单条 PATCH）/ `batch`（批量接口）/ `api`（其它程序入口）/ `legacy`（迁移回填） |
| `created_at` | 事件时间（UTC naive） |

索引：`ix_favorite_events_inspiration_time (inspiration_id, created_at)`。

**只记录真实状态变化**：重复收藏已收藏素材、重复取消未收藏素材都不写事件（接口幂等），
状态与事件在同一事务提交。素材进垃圾桶后事件保留但接口查询按未删除过滤；物理删除时
事件随外键级联删除。

### 2.3 迁移

`alembic/versions/c2d3e4f5a6b7_收藏增强_收藏时间与事件流水.py`：

- 新列可空；表/列/索引都先检查再创建，**可重入**（中断后重跑不会报错/重复）；
- 回填 `favorited_at = COALESCE(updated_at, created_at)`（仅 `is_favorite=1 AND favorited_at IS NULL`）；
- 为当前已收藏素材补一条 `source='legacy'` 的 favorite 事件（`NOT EXISTS` 去重），时间取回填值。

## 3. API

### 3.1 收藏时间与事件（A）

| 接口 | 说明 |
| --- | --- |
| `PATCH /api/inspirations/{id}` `{"is_favorite": bool}` | 状态真实变化时维护 `favorited_at` 并写事件（`source=web`）；垃圾桶素材收藏返回 400（既有规则） |
| `POST /api/inspirations/batch-favorite` `{"ids": [...], "is_favorite": bool}` | 逐条判断真实变化，仅变化项写事件（`source=batch`）；返回**实际变化条数**（`updated`） |
| `POST /api/inspirations/batch-update`（含 `is_favorite`） | 同上（`source=batch`）；与其它字段同批更新时互不影响 |
| `GET /api/inspirations/{id}/favorite-history?limit=50` | 事件流水，按时间倒序；**未知/无历史返回空**（不 404） |
| `GET /api/inspirations?sort=favorite_time` | 最近收藏倒序；未收藏（`favorited_at IS NULL`）排最后 |

`InspirationOut` 新增 `favorited_at`（ISO UTC，带 `Z`；未收藏为 `null`）。

### 3.2 收藏中心（B）

`GET /api/favorites/overview?recent_limit=12`（1~50，默认 12）：

```json
{
  "total_favorites": 120,
  "favorites_this_week": 8,
  "unrated_favorites": 35,
  "unfiled_favorites": 20,
  "recent": [/* InspirationOut，按 favorited_at 倒序，最多 recent_limit 条 */]
}
```

| 字段 | 口径 |
| --- | --- |
| `total_favorites` | 未删除且 `is_favorite=1` 的素材数 |
| `favorites_this_week` | `favorited_at` 在**近 7 天**（滚动窗口，非自然周）内的收藏数 |
| `unrated_favorites` | 收藏素材中 `rating` 为空或 0 的数量 |
| `unfiled_favorites` | 收藏素材中**不在任何手动合集**（`collections.query_json IS NULL` 的成员）里的数量；智能合集是动态求值，**不算整理** |
| `recent` | 最近收藏（`favorited_at DESC, id DESC`，NULL 排最后） |

`GET /api/favorites/history?limit=30`（1~200，默认 30）：

```json
{
  "items": [
    {
      "id": 42,
      "inspiration_id": "uuid",
      "action": "favorite",
      "source": "web",
      "created_at": "2026-11-19T10:00:00Z",
      "item": {
        "id": "uuid",
        "file_path": "images/...",
        "thumbnail_path": "thumbnails/...",
        "media_type": "image",
        "source_author": "作者",
        "is_favorite": true,
        "favorited_at": "2026-11-19T10:00:00Z"
      }
    }
  ],
  "total": 30
}
```

口径：只返回**未删除**素材的事件；按事件时间倒序。

### 3.3 合集内容搜索/筛选/排序（C）

`GET /api/collections/{id}/inspirations` 新增可选参数：

| 参数 | 取值 | 说明 |
| --- | --- | --- |
| `q` | 字符串（≤100） | 关键词模糊：`source_author` / `caption` / 标签名 |
| `media_type` | `image` / `video` | 媒体类型 |
| `quality_status` | `pending` / `approved` / `rejected` | 质量状态（空值按 pending 口径） |
| `rating_min` | 1~5 | 评分下限 |
| `is_favorite` | `true` / `false` | 收藏筛选 |
| `sort` | `manual` / `newest` / `oldest` / `rating` / `rating_asc` | 排序 |

规则：

- **手动合集**：默认 `manual`（成员 `position ASC, added_at ASC`）；筛选在分页前应用；
- **智能合集**：默认 `newest`（`created_at DESC, id DESC`）；先按 `query_json` 动态求值再叠加筛选；
  **显式 `sort=manual` 返回 400**（没有实体成员顺序，静默回退会误导前端）；
- `rating_asc` 只排已评分素材（`rating > 0`，与素材库同一口径）；
- 所有路径都排除垃圾桶素材；复用 `inspiration_query` 的筛选/加载口径（`build_filters_from_query_json`、
  `inspiration_load_options`、评分排序子句），不另写一套。

## 5. 边界与已知取舍

- **历史收藏时间不精确**：迁移只能用 `updated_at` 近似；取消过的历史收藏无法恢复时间线。
- **旧收藏的 legacy 事件**只有一条 `favorite`（没有对应的取消历史），时间取回填值。
- `batch-favorite` / `batch-update` 的 `updated` 现在表示**真实状态变化条数**（此前是所有命中行数）；
  前端如需展示「命中但未变化」可另行提示，当前 UI 仍按「操作成功」处理。
- 「未整理」只认手动合集成员；把素材放进智能合集（动态求值）不算整理——用户需要固化（solidify）
  后才计入。
- 合集 `q` 不搜文件名（与智能合集 keyword 口径区分）；如需搜文件名走素材库搜索。
- 单条收藏接口的 `source` 固定 `web`；外部程序如果直接调用批量接口会记为 `batch`
  （`api` 来源预留给后续专门集成，当前无调用方）。
- 迁移未应用到现有库前，`favorited_at` 对新库为空、旧库需执行 `alembic upgrade head`；
  新库由迁移链直接建出完整结构。
