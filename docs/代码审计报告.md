## 二、严重问题（7 项）

### S1 认证 fail-open：破坏性接口在默认配置下裸奔 ✅ 已修复（强告警）
- `config.py:116` api_key 默认空 + `main.py` 中间件空则跳过认证；绑定非回环地址时破坏性接口无鉴权。
- 修复：启动时绑定非回环地址且未配 API_KEY 时输出强告警（选择告警而非硬拒，避免破坏现有 `HOST=0.0.0.0` 部署）。

### S2 存储型 XSS：上传后缀无白名单 + 前端代理同源放大 ✅ 已修复
- `file_service.py:31` 保留原始后缀 + `files.py` 按扩展名返回 + vite 代理同源。多态图片命名 `.html` 可过 PIL 校验后在 17777 源执行，窃取 `localStorage.apiKey`。
- 修复：`_generate_filename` 扩展名白名单（非图片/视频后缀回退 `.jpg`）+ `/api/files` 仅按白名单返回媒体 MIME。

### S3 SSRF：from-url 导入无协议/内网校验 ⛔ 网络相关 · 忽略
- `inspiration_service.py:185-258` 任意 URL 可探测内网并回读内容。

### S4 数据丢失：「分析失败」批量删除用 any 语义误删已恢复素材 ✅ 已修复
- `admin.py:216-228` 用「任意失败日志」判定，会把「历史失败但最新已成功」的素材物理删除。
- 修复：统一改为「最新一条日志失败」判定（`latest_analysis_log_subquery`）。

### S5 启动时僵尸任务清理与预设标签导入静默失效 ✅ 已修复
- `main.py:105-120` 两处 UPDATE/seed 无 commit，`async_session` 退出即回滚。
- 修复：各补 `await db.commit()`。

### S6 插件 CDN 域名未授权 ⛔ 网络相关 · 忽略
- `browser-extension/manifest.json` 缺 CDN 域名，SW 跨域 fetch 被 CORS 拦截。

### S7 API Key 生成脚本与后端 .env 路径不一致 ✅ 已修复
- `scripts/generate_api_key.py` 写项目根 vs `config.py` 读 `backend/.env`。
- 修复：脚本对齐 `backend/.env`。
