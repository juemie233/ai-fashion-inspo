### 1.2 方法

先脚本化产出候选，再逐个核实（**所有临时脚本用完即删，未留任何仓库产物**）：

| 检查 | 做法 |
| --- | --- |
| Python 纯再导出模块 | AST：顶层只有 import / `__all__`，无 `def` / `class` |
| Python 纯转发函数 | AST：函数体只有一句 `return f(*args, **kw)` |
| 单实现/零实现抽象 | AST：`Protocol` / `ABC` 子类计数 |
| 死配置项 | `app/config.py` 的 `Settings` 字段 × 全仓 `settings.X` 引用计数 |
| 依赖 vs 真实 import | `requirements*.txt` / `package.json` 逐项对照 import（修正过一版：要覆盖函数体内的缩进 import） |
| 重复实现 | 前端同名函数/常量跨文件统计；后端同名函数跨模块统计；测试助手同名跨文件统计 |
| 样式重复 | `.vue` 内 `<style scoped>` 同名选择器计数 + 硬编码 hex 色值跨文件计数 |
| 组件引用次数 | 全 `web/src` 文本里 `/<组件名>.vue` 出现次数 |
| 人工核实 | 抽查包装组件内容、兼容壳注释、剪裁链路体量、工具函数语义差异 |
