## 二、高价值、与现有架构契合

### 1. 以图搜图 / 视觉相似素材推荐

- **现状**：已有 CLIP 图像向量（LanceDB，512 维）和标签相似接口，但素材层缺少「按图片找视觉相似素材」。
- **需求**：上传一张图或选择某张素材，返回向量距离最近的 Top-K 素材；支持「找同款」「找相似搭配」。
- **实现要点**：
  - 新增 `POST /api/inspirations/similar`，入参为 `image`（上传文件）或 `inspiration_id`，返回 top-K。
  - 复用现有 LanceDB 向量表与 `embedding_service`；图片上传时即时编码后查询。
  - 前端在素材详情页加「相似素材」区，首页/搜索页加入口。
- **价值**：穿搭库核心需求，投入小（向量已就绪）、收益高。

### 2. 收藏夹 / 收藏合集（Lookbook / Board）

- **现状**：仅有单素材「收藏」布尔标记。
- **需求**：建立命名合集（如「春季通勤」「黑白极简」「连衣裙参考」），把多张素材加入合集；
  可手动添加，也可按当前搜索条件「一键保存为智能合集」。
- **实现要点**：
  - 新增 `boards`、`board_inspirations` 表；支持合集封面（取首张图）、描述、排序。
  - 支持「智能合集」：保存一组筛选条件，动态匹配素材。
  - 前端合集页支持瀑布流浏览、重命名、删除、导出。
- **参考**：pinry 的 Board、各 wardrobe 项目的 Lookbook。

### 3. 颜色检索与配色分析

- **现状**：后端已有 `dominant-colors`（主色提取）接口，前端利用不足。
- **需求**：
  - 网格页提供颜色色块筛选条，点击颜色过滤主色命中的素材。
  - 素材详情展示配色板（主色 + 占比）。
  - 「找同色系」入口。
- **实现要点**：复用 `dominant-colors` 结果并入库（或在素材表加 `dominant_colors` JSON 字段）；
  前端按颜色距离做过滤。
- **参考**：home-gallery 的颜色检索。

### 4. 操作回收站 / 变更历史回滚 UI

- **现状**：后端标签有 `history` + `rollback`，但素材删除、批量改名、误合并等缺少统一「最近操作/撤销」入口。
- **需求**：
  - 全局「最近操作」面板，展示标签改名/合并、素材删除、批量编辑等。
  - 可回滚的操作提供「撤销」按钮；素材删除走软删除垃圾桶，支持还原。
  - 误合并标签后可从历史恢复。
- **实现要点**：复用并扩展 `tag_history`；为素材操作新增审计记录或复用 `audit_logs`。
- **参考**：karakeep 的完整操作历史。

## 三、中等价值

### 5. 素材详情灯箱与键盘导航

- **需求**：从网格进入详情后，支持 `←/→` 切换上一张/下一张、`Esc` 关闭、全屏翻页、滚轮缩放。
- **实现要点**：封装统一的 `ImageLightbox`（项目中已有 `ImageLightbox` 组件可增强），在网格/详情/合集间共享。
- **价值**：图库浏览体验的基础项，成本低。

### 6. 标签 / 人物订阅与更新提醒

- **需求**：关注某博主或标签，有新素材入库时在导航栏显示角标/未读数。
- **实现要点**：新增 `subscriptions` 表（类型 tag/person，目标 id）；入库任务触发未读计数；前端轮询或 SSE。

### 7. 统计仪表盘增强

- **需求**：整合入库趋势、各类别素材占比、博主产出排行、采集来源分布、标签增长曲线为首页 Dashboard。
- **实现要点**：复用 `effect/*` 与 `stats` 接口数据，新增 1~2 个聚合接口；用现有 `ArcoChart` 可视化。

## 四、低优先 / 较大工程

### 8. 近重复图片检测与去重

- **现状**：已有标签去重和向量语义相似，但缺少像素级近重复检测。
- **需求**：用 pHash/dHash 找出几乎相同的图片（同一图不同尺寸、水印、压缩），在采集入库时提示或自动归并。
- **实现要点**：入库时计算感知哈希；新增 `images` 哈希索引与去重任务面板。

### 9. 移动端 PWA / 手机上传

- **需求**：手机浏览器可拍照/选图上传、浏览素材、查看标签；支持添加到主屏幕。
- **实现要点**：Vite PWA 插件 + manifest；优化移动端布局；上传接口已支持。
- **参考**：home-gallery 主打移动端。
