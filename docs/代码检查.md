## 后端：死代码（vulture）

```bash
cd backend
pip install -r requirements-dev.txt        # 含 vulture
python -m vulture app --min-confidence 80  # 必须 0 条
```

- **门禁口径**：`--min-confidence 80` 下必须 **0 条**（2026-10 已清零）。
- 确实需要保留但被误报的符号（FastAPI 装饰器注册、Pydantic 回调、框架约定参数等），
  用 `python -m vulture app --min-confidence 80 --make-whitelist > vulture_whitelist.py`
  生成基线，然后跑 `python -m vulture app vulture_whitelist.py --min-confidence 80`。
  **只往白名单里加「确认要保留」的项**，不要为了过门禁而整批加进去。
- 本轮清理掉的 4 条真实死代码：`database.py` 未用的回调参数、`inspiration_create.py` 两个
  未用 import、`tag_batch_edit.py::_format_preview` 未使用的 `tags_by_id` 参数。
