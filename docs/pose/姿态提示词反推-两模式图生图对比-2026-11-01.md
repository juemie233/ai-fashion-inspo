## 1. 目的与假设

**目的**：回答两个问题：

- H1：把同一批姿态分别用「thinking 反推」和「非 thinking 反推」得到的提示词，送进同一图生图链路，出图的**姿势跟随**和**画面质量**有没有差异；
- H2：两种模式的反推成本（token / 耗时）差多少。

**不验证**：不同素材、不同姿态体系、不同图生图参数（这些保持固定）。

## 4. 判断与建议

1. **H1 不成立**：thinking 反推提示词的下游姿势跟随 4.15 vs disabled 4.00，差异小于单 seed、单素材的人工评分噪声；两版在身份/服装/画面质量上也相当；
2. **H2 成立但代价不大**：反推阶段输出 token +43.0%、单条耗时 +1.1 s；生成阶段耗时与提示词长度无关（均 ~90 s/张）；
3. **结论**：这类「姿态线稿 → 图生图提示词」反推**默认不开 thinking 即可**；thinking 只适合需要审阅推理过程或提示词要求非常复杂的场景；
4. 本轮**未验证**多素材/多 seed/多人盲评；若要更强结论，建议扩到 3 个素材 × 2 seed，但这不影响当前「无明显收益」的判断。
