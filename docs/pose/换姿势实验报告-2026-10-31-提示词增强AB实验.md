# 换姿势实验报告：提示词增强 A/B（对照组 / +描述词 / +描述词+负向词）

> **状态**：已结项（2026-10-31 单次实验）。**结论先行：加描述词没有稳定收益；在当前配置（cfg=1.0）下加负向词完全无效——G1 与 G2 逐像素相同；只有把 cfg 提到 3.0，负向词才开始起作用。**
> 实验对象：随机 10 张 4 星及以上素材 × 全身单人・性感系随机 3 个姿态；每组 10 张，共 30 张。
> 数据与对比图：`G:/fashion-inspo-storage/poc/pose_prompt_ab_20261031/`（对比图不入库）。

## 1. 目的与假设

**目的**：在「换姿势」当前默认链路上，只改提示词，验证两件事是否有效：

- **H1（+描述词）**：在原姿势模板后追加一段通用高质量描述词（写实/8K/皮肤质感/光线/细节），
  能否提升姿势跟随、画面细节与整体观感；
- **H2（+描述词+负向词）**：再追加负向描述（多余肢体/多余手指/畸形/模糊等），
  能否进一步减少手/肢体畸变。

**不验证**：换模型、换工作流、改控制强度、改采样参数（这些保持"目前配置"）。

## 3. 结果

### 3.1 关键发现：负向词完全无效（H2 = 否）

**cfg=1.0 时 G1 与 G2 的输出逐像素完全相同（10/10）**——PNG 文件字节因元数据不同而不同，
但 RGB 像素数组完全一致。原因：Qwen-Image 2.1 蒸馏档位推荐 `CFG=1.0`，CFG 缩放不计算
无条条件分支，**负向提示词根本不参与采样**（此前 P0 实验也验证过这一点）。

> 因此「实验组 2」在当前配置下**等价于实验组 1**，不是"加了负向词没变好"，而是**负向词没有被模型读取**。

### 3.2 描述词的效果（H1 = 不显著）

人工评分（1~5，对照 sheet 逐样本目视；G2 与 G1 相同故只列 G1）：

| 指标 | 对照组 | 实验组 1（+描述词） | 变化 |
| --- | ---: | ---: | --- |
| 姿势跟随均分 | **2.8/5** | **3.1/5** | +0.3（s03/s05/s06 略好，其余持平） |
| 身份余弦（InsightFace，n=9，s02 侧脸无脸） | **0.791** | **0.750** | **-0.041**（s04 -0.33 最差，s09/s10 +0.04 略好） |
| 画面细节/观感 | 基准 | 主观变化很小，个别样本场景/背景被改动（s06 从绿椅场景变为床/白背景） | 无稳定收益 |
| 手/肢体畸变 | 偶发（s02/s05） | 与对照相当，没有可确认的改善 | — |
| 单张耗时 | 86.4 s | 87.9 s | 基本持平 |

**逐样本姿势评分**（对照 / G1）：s01 4/4、s02 2/2、s03 2/3、s04 4/4、s05 3/4、s06 2/3、s07 4/4、s08 3/3、s09 2/2、s10 2/2。

### 3.3 补充验证：把 CFG 提到 3.0 后负向词才生效

在 s01 上补跑 2 张（其它参数不变，只把 CFG 从 1.0 改为 3.0）：

| 组合 | 与同 CFG=1.0 的结果 | 说明 |
| --- | --- | --- |
| CFG=3.0 + 描述词（无负向） | 与 CFG=1.0 差异明显 | 画质更干净，**源图的手机状态栏/播放 UI 被消除**（CFG=1.0 时会照抄） |
| CFG=3.0 + 描述词 + 负向词 | 与 CFG=3.0 无负向**像素不同**（平均绝对差 8.99/255） | 负向词开始参与采样，手/脚/鞋细节有可见变化 |

> 这是**额外发现**，不是原三组实验的结论：`cfg=1.0` 是当前产品默认（速度/稳定性最好），
> 但它同时意味着「负向词无效 + 源图 UI 会被照抄」。若要把负向词用起来，需要单独做
> 「CFG 提高」的对比实验（会牺牲速度与稳定性）。

## 4. 判断与建议

1. **H1 不成立（无稳定收益）**：加一段通用高质量描述词，姿势 +0.3/5、身份 -0.04、画质主观无稳定提升，
   且出现「背景/场景被改写」的副作用。当前阶段**不建议默认加描述词**；用户可在描述框自行写需求。
2. **H2 不成立（无效，而非变差）**：`cfg=1.0` 下负向词完全不参与采样，G1/G2 逐像素相同。
   **不要再在当前默认配置里堆负向词**；要让它生效必须提高 CFG 或换工作流。
3. **额外发现值得单独验证**：CFG=3.0 能去掉源图手机 UI 并让负向词生效，但单张耗时从 ~86 s 涨到 ~161 s，
   且可能降低姿势/身份的稳定性——建议作为下一次独立实验（CFG 1.0 / 2.0 / 3.0 对比），不要直接改产品默认。
4. **姿势跟随仍是主要瓶颈**（均分 2.8~3.1/5，多数样本保持原图姿势）——这与之前结论一致：
   线稿作为参考图时 Qwen 编辑会优先保留源图姿态，prompt 微调救不了，需要换控制方式（已结项）。

## 5. 局限

- 单 seed、每组合只跑 1 次，无法估计随机方差；评分是单人人工目视，主观性较强；
- 素材中有几张是带手机状态栏的截图，输出把 UI 一起画进去了，污染了质量评分；
- 实验组 2 与实验组 1 在 cfg=1.0 下等价，因此实际上只比较了「描述词 vs 无描述词」两组。
