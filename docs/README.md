## 新增文档约定

1. 文件名用中文（技术专名可保留，如 `ComfyUI`、`CLIP`），放 `docs/`；
2. 文首写状态：`现行` / `已结项` / `已归档` / `历史快照`，并给日期与一句话结论；
3. 实验报告必须含：目的与假设、流程与参数、量化结果、图片对比（注明 storage 路径）、判断与下一步；
4. 删除或改名文档时，同步更新本索引与全仓引用。
