# 姿势图库换姿势（路径一）实现说明

> 对应分支 `feat/pose-i2i`；范围：素材详情「换个姿势」→ 出图页自动打开姿势选择器 →
> 选姿势 → 模特换成该姿势 → 生成候选图。**个人本地使用**，不做内容分级过滤。
> 评估背景见 [`docs/模特素材换姿势图生图链路评估.md`](模特素材换姿势图生图链路评估.md)（路径一）。

## 1. 链路与数据流

```text
[素材详情页] 点「换个姿势」
   └─ 路由 /generate?ref=<素材id>&pose_lib=1
        └─ 出图页（GenerateView）读取 pose_lib → 参数面板挂载后自动打开姿势选择器
             ├─ 参考素材：ref 预填为第 1 张（主体：人物/服装）
             └─ 选姿势：GET /api/pose-gallery（后端代理 ai-pose-gallery-zh）
                  └─ 提交生成（kind=i2i + reference_ids + pose_id）
                       └─ 执行器把姿势图**追加为最后一张参考图**后再走现有 Qwen-Image 2.1
                          「多参考图编辑」工作流（无需新档位/新模板）
                            └─ 候选区 → 勾选入库（沿用现有两段式）
```

**参考图顺序约定**：第 1 张（及前面几张）是主体参考，**最后一张是姿势图**。参数面板的
「插入姿势描述」会生成一段提示词模板明确这个顺序（模型才不会把主体也改掉）。

## 2. 后端

| 模块 | 职责 |
| --- | --- |
| `app/services/pose_gallery.py` | 拉取源站 `data/pose-zh.json` → 归一化（id/名称/体系/分类/角度/缩略图/原图直链）；缓存到 `storage/pose_gallery/catalog.json`（默认 12 小时，过期回源，回源失败用旧缓存兜底）；按需下载原图到 `storage/pose_gallery/images/<id>.png`（生成时才下载，不随仓库分发图片） |
| `app/routers/pose_gallery.py` | `GET /api/pose-gallery`（筛选+分页）、`GET /api/pose-gallery/meta`（筛选项） |
| `app/schemas/generation.py` | `GenerationRunCreate.pose_id`（≤64 字符） |
| `app/services/generation_service.py` | 提交校验：姿势只对 `kind=i2i` 开放；姿势必须存在于目录；姿势图占 1 张参考额度（主体参考 ≤9 张）；`pose_id` 写进 `params_json`；`retry_run` / `regenerate_candidate` 原样带上姿势 |
| `app/services/task_runners/image_gen.py` | 参考图上传完后再下载并上传姿势图（文件名 `gen_pose_<run_id>.png`），追加到 `reference_names` 末尾；下载失败按永久错误给出可读原因 |
| `app/config.py` | `pose_gallery_base_url`（默认 `https://ai-pose-gallery.anhao.app`）、`pose_gallery_cache_hours`（12） |

为什么由后端代理而不是前端直连：源站是 GitHub Pages 静态站，`/data/pose-zh.json`
**没有 CORS 头**（实测），浏览器跨域 `fetch` 会被拦；后端缓存后前端只跟本机接口打交道，
源站抖动也有旧缓存兜底。缩略图/原图地址仍是源站直链（`<img>` 展示不需要 CORS）。

**不做内容分级**：这是个人本地项目，源站 4 个体系（含成人向）都可选；只保留两条底线——
不随仓库分发图片（`img/`、`thumbs/` 不入库）、生成结果仍走「AI 生成」标记。

## 5. 边界与后续

- **姿势一致性不保证**：当前复用 Qwen-Image 2.1 多参考图编辑（评估里的 R1 路线），
  姿势「像」但不保证逐关节一致；如需更强控制，后续可加 SDXL + ControlNet(lineart) 档位
  （评估里的 R2），数据侧已能按 `pose_id` 取原图与缓存路径。
- **源站依赖**：首次使用需要能访问 ai-pose-gallery.anhao.app（个人环境已验证可访问）；
  离线时可先手动放一份 `storage/pose_gallery/catalog.json` 兜底。
- **版权**：姿势图版权归原作者，仅本地个人使用，不随仓库分发、不对外提供公开生成服务。
