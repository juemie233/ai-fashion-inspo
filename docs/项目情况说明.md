## 1. 项目定位

**AI 穿搭素材库（fashion-inspo）** 是单机本地运行的穿搭素材管理工具：通过自动采集（小红书 / 抖音 / 浏览器插件）与本地视觉 AI 识别，把碎片化穿搭内容变成可智能检索（关键词 / 标签 / 颜色 / 语义 / 以图搜图）的专属素材资产。

核心特点：**全部本地运行**（无云依赖）、**AI 打标 + 质量审核闭环**、**多渠道采集**、**人物/博主维度管理**、**ComfyUI 本地出图**。

## 2. 技术栈

| 层级 | 技术 | 说明 |
| --- | --- | --- |
| 后端 | Python 3.12 + FastAPI + SQLAlchemy async + SQLite（WAL） | REST API + WebSocket，端口 18888 |
| 任务队列 | 独立 worker 进程（`python -m app.worker`） | 批量分析/审核/删除/去重/向量回填/出图异步化 |
| Web 前端 | Vue 3 + Vite + TypeScript + Pinia + Arco Design | 端口 17777 |
| 移动端 | React Native (Expo) + Zustand | 画廊/搜索/拍照上传 |
| 浏览器插件 | Chrome Extension Manifest V3 | 一键提取网页穿搭图 |
| AI 推理 | Ollama + Qwen3-VL:8B-Instruct（本机 GPU，RTX 5060 Ti 16GB） | 视觉打标 + 质量审核 |
| 向量检索 | LanceDB + all-minilm（文本 384 维）/ CLIP ViT-B/32（图像 512 维） | 语义搜索 + 以图搜图 + 相似推荐 |
| 采集引擎 | Playwright + CDP 连接真实 Chrome | 小红书零检测、抖音独立浏览器（依赖上游 f2） |
| 本地出图 | ComfyUI（`D:\AI\ComfyUI`） | Z-Image-Turbo / Qwen-Image 2.1（含未审查版）文生图与参考图改款 |
| 数据库迁移 | Alembic | schema 版本管理 |
