> 本文档面向首次接触项目的人（或需要快速了解现状的协作者），说明项目的定位、技术栈、功能完成度、数据规模、近期进展、技术债与下一步计划。详细的安装使用与 API 见 [README](../README.md)，待办清单见 [TODO](../TODO.md)，编码规范见 [CLAUDE](../CLAUDE.md)。

## 1. 项目定位

**AI 穿搭素材库（fashion-inspo）** 是专为个人打造的穿搭素材管理工具：通过自动化采集（小红书/抖音/浏览器插件）与本地视觉 AI 识别，把碎片化的穿搭内容转化为可智能检索（关键词/标签/颜色/语义/以图搜图）的专属素材资产。

核心特点：**全部本地运行**（无云依赖）、**AI 打标 + 质量审核闭环**、**多渠道采集**、**人物/博主维度管理**。

## 2. 技术栈

| 层级 | 技术 | 说明 |
| ------ | ------ | ------ |
| 后端 | Python 3.12 + FastAPI + SQLAlchemy async + SQLite | REST API + WebSocket，端口 18888 |
| 任务队列 | 独立 worker 进程（`python -m app.worker`） | 批量分析/审核/删除/去重异步化 |
| Web 前端 | Vue 3 + Vite + TypeScript + Pinia + Naive UI | 端口 17777 |
| 移动端 | React Native (Expo) + Zustand | 画廊/搜索/拍照上传 |
| 浏览器插件 | Chrome Extension Manifest V3 | 一键提取网页穿搭图 |
| AI 推理 | Ollama + Qwen3-VL:8B-Instruct（本地 GPU，RTX 5060Ti 16GB） | 视觉打标 + 质量审核 |
| 向量检索 | LanceDB + all-minilm（文本 384 维）/ CLIP ViT-B/32（图像 512 维） | 语义搜索 + 以图搜图 + 相似推荐 |
| 采集引擎 | Playwright + CDP 连接真实 Chrome | 小红书零检测、抖音独立浏览器 |
| 数据库迁移 | Alembic | schema 版本管理 |

## 4. 数据规模与运行环境

- **素材**：3000+ 张（含图片/视频，标签体系 8 大类：风格/单品/颜色/穿着方式/版型/季节/图片属性/穿搭大标签）
- **向量**：文本 + 图像向量存于 LanceDB（本地文件落盘，可随项目迁移）
- **运行环境**：Windows 11、Python 3.12+、Node.js 20+、Ollama、ffmpeg（视频关键帧，预留）、Google Chrome（CDP 采集）
- **存储布局**：`backend/storage/` 下 images / thumbnails / videos / trash（垃圾桶）/ person_photos（人物照片）/ person_thumbnails / lancedb（向量）
