## 1. 项目定位

**AI 穿搭素材库（fashion-inspo）** 是专为个人打造的穿搭素材管理工具：通过自动化采集（小红书/抖音/浏览器插件）与本地视觉 AI 识别，把碎片化的穿搭内容转化为可智能检索（关键词/标签/颜色/语义/以图搜图）的专属素材资产。

核心特点：**全部本地运行**（无云依赖）、**AI 打标 + 质量审核闭环**、**多渠道采集**、**人物/博主维度管理**。

## 2. 技术栈

| 层级 | 技术 | 说明 |
| ------ | ------ | ------ |
| 后端 | Python 3.12 + FastAPI + SQLAlchemy async + SQLite | REST API + WebSocket，端口 18888 |
| 任务队列 | 独立 worker 进程（`python -m app.worker`） | 批量分析/审核/删除/去重/向量回填异步化（向量回填攒批机制） |
| Web 前端 | Vue 3 + Vite + TypeScript + Pinia + Arco Design（@arco-design/web-vue） | 端口 17777（已全量替换 Naive UI） |
| 移动端 | React Native (Expo) + Zustand | 画廊/搜索/拍照上传 |
| 浏览器插件 | Chrome Extension Manifest V3 | 一键提取网页穿搭图 |
| AI 推理 | Ollama + Qwen3-VL:8B-Instruct（本地 GPU，RTX 5060Ti 16GB） | 视觉打标 + 质量审核 |
| 向量检索 | LanceDB + all-minilm（文本 384 维）/ CLIP ViT-B/32（图像 512 维） | 语义搜索 + 以图搜图 + 相似推荐 |
| 采集引擎 | Playwright + CDP 连接真实 Chrome | 小红书零检测、抖音独立浏览器 |
| 数据库迁移 | Alembic | schema 版本管理 |

## 4. 数据规模与运行环境

- **素材**：**数万条**（抖音采集为主 + 手动上传 + 采集通道，含图片与视频），
  标签体系 8 大类：风格/单品/颜色/穿着方式/版型/季节/图片属性/穿搭大标签
- **标签**：上万个标签、数十万条标签关联（每素材约 20 条）
- **数据库**：`backend/fashion_inspo.db` 数百 MB 量级（WAL 模式）；容量评估与增长投影
  是**本地私有文档**（含真实数据统计，`.gitignore` 已排除、不随仓库公开）
- **向量**：文本 + 图像向量存于 LanceDB（本地文件落盘，可随项目迁移）
- **运行环境**：Windows 11、Python 3.12+、Node.js 20+、Ollama（打标/审核）、ffmpeg（视频关键帧）、
  Google Chrome（CDP 采集）、**ComfyUI**（本地出图，装在 `D:\AI\ComfyUI`，16 GB 显存；见
  [ComfyUI 环境与出图模型](./ComfyUI环境与出图模型.md)）
- **存储布局**：`backend/storage/` 下 images / thumbnails / videos / keyframes / trash（垃圾桶）/
  person_photos（人物照片）/ person_thumbnails / generated（出图候选区）/ lancedb（向量）
