## 新增文档约定

1. **先选目录**：按主题放进 `overview/` `mobile/` `features/` `pose/` `ops/` `archive/` 之一；
   没有合适的目录时先与用户确认，新目录需登记进 CLAUDE.md「项目结构」与本文件目录表；
2. 文件名用中文（技术专名可保留，如 `ComfyUI`、`CLIP`），与同目录既有文档的命名风格一致；
3. 文首写状态：`现行` / `已结项` / `已归档` / `历史快照`，并给日期与一句话结论；
4. 实验报告必须含：目的与假设、流程与参数、量化结果、图片对比（注明 storage 路径）、判断与下一步；
5. 删除、改名或移动文档时，同步更新本索引与全仓引用（`grep -rn "docs/<旧路径>"` 自查）。
