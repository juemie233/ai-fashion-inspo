**实测（2026-10-21，本机没有可用代理）**：

| 目标 | 直连 | 可用替代 |
| --- | --- | --- |
| `github.com` | ❌ 超时（`000`） | ✅ `https://gh-proxy.com/https://github.com/...`（`ghfast.top` / `kkgithub` / `hub.gitmirror` 均不通；`ghproxy.net` 返回 403） |
| `huggingface.co` | ❌ 超时（`000`） | ✅ `https://hf-mirror.com`（`/resolve/main/<路径>?download=true` 可直接喂给 curl） |
| `download.pytorch.org` | ✅ 200 | 需要升级 torch 时可用官方源 |

⚠️ **踩过的坑（参数照抄）**：hf-mirror 下大文件时连接会「假活」——进程还在、文件不再增长
（实测卡在 5.21 GB / 6.20 GB 不动），`curl` 必须带**停速检测**才会自己断开重连续传：

```powershell
# -C - 续传；--speed-limit/--speed-time：20 秒低于 100 KB/s 就断开重来
curl.exe -L -C - --connect-timeout 20 --speed-limit 102400 --speed-time 20 `
  --retry 8 --retry-delay 5 --retry-all-errors -o 目标文件 "https://hf-mirror.com/<repo>/resolve/main/<路径>?download=true"
```

下载完**必须验 sha256**（镜像不保证零错漏），期望值从 HF API 取：

```powershell
curl.exe -s "https://hf-mirror.com/api/models/Comfy-Org/z_image_turbo/tree/main?recursive=true"
# 每个 LFS 文件都带 size 与 lfs.oid（= sha256），与本机 certutil -hashfile <文件> SHA256 对比
```

## 8. 故障对照表（按症状查）

| 症状 | 常见原因 | 处理 |
| --- | --- | --- |
| 启动报 `no kernel image is available` / 提到 `sm_120` | PyTorch 的 CUDA < 12.8（Blackwell 不支持） | 按 2.2 升级到 cu128 及以上，重跑校验 |
| `torch.cuda.is_available()` 为 False | 装成了 CPU 版 torch，或驱动太旧 | 重装 cu128 轮子；确认 `nvidia-smi` 正常 |
| 加载模型时 `Allocation on device` / OOM | 选了 bf16/fp16 大模型，或 Ollama 还占着显存 | 换 int8/fp8/GGUF Q4；先 `ollama stop` |
| 模型列表里看不到刚下的文件 | 放错目录（diffusion / text_encoders / vae / checkpoints） | 按第 3 节目录约定移动，刷新页面 |
| 节点 `Unet Loader (GGUF)` 不存在 | 没装 ComfyUI-GGUF 插件 | 按档位 C 的命令安装并重启 |
| 出图糊 / 全黑 | 文本编码器或 VAE 选错（尤其 Flux 系要 `t5xxl` + `ae`） | 核对三个加载节点 |
| 出图**整张纯噪声**（跑得完、进度 100%、ComfyUI **不报错**） | `CLIPLoader` 的**权重与 type 不成对**：如把提示词改写 LLM `pe_i2i` 当编码器，或给 Qwen 编码器填 Z-Image 的 `lumina2` | Qwen-Image 2.1 → `qwen3vl_8b_w4a8` + type `qwen_image`；Z-Image → `qwen_3_4b_fp8_mixed` + type `lumina2`。成因与实测见设计文档 15.6.1 |
| 下载到一半失败 | HF 直连不稳 | 设 `HF_ENDPOINT=https://hf-mirror.com`，用支持续传的命令重试 |
| 出图极慢（> 5 min/张） | 模型被 CPU offload（内存不足 16 GB 常见） | 降分辨率/换小模型；考虑加内存 |
| 浏览器打不开 8188 | 端口被占 / 进程已退出 | `Get-NetTCPConnection -LocalPort 8188`；换端口或重开 |
